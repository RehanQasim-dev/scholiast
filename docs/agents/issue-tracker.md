# Issue tracker: GitHub Issues

Issues for this repo live on GitHub at `RehanQasim-dev/scholiast`.

## Conventions

- Create issues using the `gh` CLI: `gh issue create --title "..." --body "..."`
- Fetch issues using `gh issue view <number>`
- Reference issues in commits: `fix: ... Closes #123`
- For substantial features, design and specs are documented in `specs/<feature-slug>/PRODUCT.md` and `TECH.md`.
