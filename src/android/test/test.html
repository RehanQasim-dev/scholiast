Why highlights survive reflows

A highlight anchored only to byte offsets dies the moment a layout shifts. The kernel therefore stores two anchors: a structural XPath for the fast path and a text-quote anchor — quote, prefix, suffix, occurrence — that finds the same words even after the page has been cleaned, re-rendered or synced elsewhere.

  1. Select any sentence — the swatch pill floats above the selection start.
  2. Tap a color — the highlight paints through the Custom Highlight API at 32% alpha and a 💬 badge lands at the span end.
  3. Scroll — the pill hides immediately; scroll back and the highlight is still there.
